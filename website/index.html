Linux Server Deployment & Monitoring

A Hands-on DevOps Project

🚀 Project Overview

This project demonstrates the deployment and monitoring of a Linux-based web server using DevOps tools and automation.

The project starts with Linux and Bash automation and will progressively integrate AWS, Docker and Jenkins CI/CD.

🛠️ Technologies

Linux Bash Git GitHub AWS EC2 Nginx Docker Jenkins

  • ✅ Project initialization
  • 🔨 Website development
  • ⏳ Bash deployment automation
  • ⏳ AWS EC2 deployment

  • ⏳ Docker containerization
  • ⏳ Jenkins CI/CD
