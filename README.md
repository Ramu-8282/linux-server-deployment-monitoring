# Linux Server Deployment & Monitoring

A hands-on DevOps project focused on automating Linux server deployment,
web application hosting, and basic server health monitoring.

## Project Objective

The objective of this project is to build and automate a Linux-based
web server environment using Bash scripting, AWS EC2, Nginx, Git,
Docker, and eventually Jenkins CI/CD.
